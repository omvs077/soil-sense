A security-hardened, explainable multiclass Machine Learning system classifying soil fertility status (Low, Medium, High) based on chemical, physical, and environmental parameters, running with zero C: drive storage bloat.

STACK: Scikit-learn • Pandas • Pydantic • Streamlit SECURITY: CWE-502 SHA-256 Verified STATUS: Live on Streamlit Cloud
01 • Problem Statement

The Challenge of Modern Soil Diagnostics

⚠️ Laboratory Bottlenecks

  • High Turnaround Latency: Traditional wet-chemistry soil assays take 2 to 4 weeks for laboratory results.
  • Multidimensional Complexity: Interpreting 8+ interacting parameters (NPK, pH, EC, moisture) requires agronomic specialists.
  • Blind Chemical Over-fertilization: Incorrect fertilizing exacerbates soil acidification, groundwater leaching, and crop lodging.

💡 The Soil-Sense Solution

  • Instant Supervised Inference: Real-time multiclass classification (Low / Medium / High) in under 50 milliseconds.
  • Prescriptive Actionable Advisories: Diagnostic heuristics mapping deficits to ICAR/FAO soil amendment treatments.
  • Zero Cloud Dependency: Fully sandboxed local execution on D: drive or serverless cloud deployment.
02 • Engineering Architecture

System Architecture & Zero C: Drive Bloat

1. Core Stack

  • Runtime: Python 3.12 / 3.14
  • ML Engine: Scikit-learn (Pipelines, Scalers, Imputers)
  • Data Engine: Pandas & NumPy
  • Validation: Pydantic v2 schemas
  • Frontend: Streamlit + CSS Grid

2. Zero Data Leakage

  • Strict Encapsulation: Transformers bound in Pipeline.
  • Independent Fitting: Scaler fits strictly on X_train during training.
  • Consistent Inference: Same pipeline transforms production inputs.

3. C: Drive Protection

  • Virtualenv on D: .venv created inside project directory.
  • Pip Cache Redirection: pip config set global.cache-dir D:\pip-cache.
  • Ultra-Lightweight: Footprint < 400 MB (vs > 3.5 GB for Deep Learning frameworks).
03 • Dataset & Agronomy

8 Physicochemical Parameters & Reference Standards

🧪 8 Input Parameters

  • Nitrogen (N): Vegetative vegetative growth ($140 - 280\text{ mg/kg}$ optimal).
  • Phosphorus (P): Root growth and ATP energy ($15 - 30\text{ mg/kg}$ optimal).
  • Potassium (K): Drought and stomatal resistance ($130 - 280\text{ mg/kg}$).
  • Soil pH: Chemical acidity/alkalinity ($6.2 - 7.5$ ideal neutral).
  • Electrical Cond. (EC): Salinity threshold ($< 1.0\text{ dS/m}$ non-saline).
  • Moisture & Microclimate: Moisture ($25 - 60\%$), Temp & Humidity.

🌾 ICAR / FAO Classification

  • High Fertility (🟢): Optimal NPK balance, neutral pH, low salinity, good moisture retention.
  • Medium Fertility (🟡): Moderate nutrient deficit or slight pH imbalance; correctable with starter amendments.
  • Low Fertility (🔴): Severe nutrient depletion, extreme pH ($< 5.5$ or $> 8.5$), or severe osmotic salinity ($EC > 2.5$).

05 • Security & Hardening

Cybersecurity & Defense-in-Depth

🛡️ Deserialization Defense (CWE-502)

  • Attack Vector: Python pickle / joblib formats execute arbitrary bytecode upon deserialization.
  • Cryptographic Verification: Computed SHA-256 digest at training time saved in models/model_checksum.json.
  • Runtime Checksum Guard: SoilPredictor validates hash before unpickling; blocks modified or tampered files.

🔒 Schema Boundary Enforcement

  • Pydantic v2 Schema: Enforces physical constraints ($0 \le \text{pH} \le 14$, non-negative nutrients, bounded moisture).
  • Injection Shield: Strictly rejects string injections, NaNs, and infinite float values.
  • Automated Test Suite: 8 unit tests in pytest validating schema boundaries and cryptographic defenses.
